# 一路騎台灣 Ride Taiwan

騎著機車，載著旅伴，從埔里一路騎上武嶺。一款悠閒的台灣公路旅行小遊戲。

**▶ 立即遊玩：https://akirayeh.github.io/ride-taiwan/**

電腦或手機瀏覽器都能玩（手機請轉成橫向）。一趟旅程大約 20～25 分鐘。

## 特色
- 選擇小玟或阿敬當騎士，另一人坐後座一起出發
- 埔里市區 → 鄉間稻田 → 霧社山路 → 清境草原 → 合歡山公路
- 景點：埔里酒廠、桃米紙教堂、霧社碧湖、清境青青草原、清境高空觀景步道、武嶺（海拔 3275 公尺）
- 拍照模式、明信片、紀念章、旅途回憶
- 路上小事件：水果攤、台灣獼猴、午後雷陣雨與彩虹
- 可選出發時段（清晨／午後／黃昏）與天氣
